# Signaler une faille

Si vous trouvez une faille dans l'agent ou dans le dictionnaire, ne l'écrivez pas dans une
issue publique. Utilisez le signalement privé de GitHub, onglet « Security » de ce dépôt,
« Report a vulnerability », ou écrivez à contact@pharma2a.org. Vous recevez une réponse sous cinq jours ouvrés, et le
correctif est publié avec une version et une entrée dans CHANGELOG.md.

Un agent en service ne doit jamais exposer sa carte étendue, ses tâches ni sa boîte sans
jeton ; si vous voyez un agent PharmA2A qui le fait, dites-le au fournisseur qui l'opère.
