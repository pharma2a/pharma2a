# Maintainers

PharmA2A is maintained by **SyderaAI**, Paris, which holds the protocol and the PharmA2A
name (see `GOVERNANCE.md` and `TRADEMARK.md`).

| Area | Maintainer | Contact |
|---|---|---|
| Dictionary (`schema/`) | SyderaAI | contact@pharma2a.org |
| Supplier agent (`pharma2a/`) | SyderaAI | contact@pharma2a.org |
| Security reports | SyderaAI | GitHub private vulnerability reporting, or contact@pharma2a.org (see `SECURITY.md`) |

Maintainers review pull requests, decide what enters the dictionary, publish versions and
answer reports. A regular contributor who wants to maintain an area can ask in an issue.
