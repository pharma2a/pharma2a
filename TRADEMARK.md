# Le nom PharmA2A

PharmA2A est une marque déposée de SyderaAI, société établie à Paris (dépôt INPI du 30 octobre 2026). Le contenu de ce dépôt est libre : le dictionnaire est
dans le domaine public (CC0 1.0), l'agent est sous licence Apache 2.0. Le nom ne l'est pas.

Ce qui est permis sans demander :

- dire qu'une implémentation « parle PharmA2A » ou « est conforme à PharmA2A version 1 »,
  quand elle parle le dictionnaire tel qu'il est publié ici, sans champ de plus ;
- citer le nom dans une documentation, un article, une présentation ;
- reprendre, modifier et redistribuer le code et les schémas, sous leurs licences.

Ce qui ne l'est pas :

- appeler un produit, un service, un dépôt ou un protocole « PharmA2A », ou un nom qui
  s'y confond (« PharmA2A 2.0 », « PharmA2A Pro », « OpenPharmA2A ») ;
- laisser entendre qu'une implémentation est faite, validée ou soutenue par SyderaAI quand
  elle ne l'est pas ;
- utiliser le nom pour un échange qui n'est pas conforme au dictionnaire publié.

Une version dérivée du dictionnaire se publie sous un autre nom. Une proposition de
changement se fait ici, par une issue, pour entrer dans la version suivante de PharmA2A.
